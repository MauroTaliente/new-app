# new-app

Monorepo (`pnpm` workspaces): shared libraries under `packages/*` and apps under `apps/*`.

**Documentation:** [English](README.en.md) · [Español](README.es.md)

## Quick start

```bash
pnpm install
pnpm run build:packages
pnpm run generate   # demo: styles + API modules from lib.config.json
pnpm test
```

See [README.en.md](README.en.md) for layout, packages, and codegen.
