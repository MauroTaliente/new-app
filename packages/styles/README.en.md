# @react33/react-styles

## `react-styles-generate` — config

The CLI walks **up** from `cwd` looking for (first match wins):

- `.react33.config.json`
- `react33.config.json`
- `react33-styles.config.json`

### JSON Schema — IDE autocomplete

You **do not** need to repeat `$schema` in every `react33.config.json` if the repo defines **`json.schemas`** in `.vscode/settings.json` (Cursor/VS Code): map `**/react33.config.json` to `./node_modules/@react33/react-config/react33.config.schema.json` from the **workspace root** (where `node_modules` lives after `pnpm install`).

If you open only a subfolder as the workspace or use another editor, declare the schema in the JSON file:

```json
{
  "$schema": "./node_modules/@react33/react-config/react33.config.schema.json",
  "react33Styles": {
    "cssDir": "./src/theme",
    "domainsOrder": ["tokens", "palette", "theme"],
    "stylesOutput": "./src/theme/styles.generated.ts"
  }
}
```

Global `react33.config.json` schema: [`@react33/react-config`](../config) package (not shipped from `react-styles`).

Use a `react33Styles` object:

```json
{
  "react33Styles": {
    "cssDir": "./src/theme",
    "domainsOrder": ["tokens", "palette", "theme"],
    "stylesOutput": "./src/theme/styles.generated.ts",
    "excludeStems": ["scratch", "wip"],
    "metaSourceStem": "tokens",
    "banner": "// Generated by react33-styles — do not edit.",
    "verbose": false,
    "watch": false
  }
}
```

(Omit `$schema` when using the workspace association.)

### Paths

- `cssDir`, `stylesOutput` are resolved **relative to the config file’s directory** (like `tsconfig.json`).

### Order of domains (cascade / `var()` resolution)

1. **`--domains` on the CLI** (highest priority)
2. **`react33Styles.domainsOrder`** in config
3. **Otherwise**: every `*.css` in `cssDir`, sorted **A→Z** by filename (locale `en`, base sensitivity).  
   Files named `*.generated.css` are ignored.  
   Stems listed in **`excludeStems`** are skipped (only applies to this auto-discovery mode).

### Other `react33Styles` fields

| Field | Purpose |
|-------|--------|
| **`excludeStems`** | Stems to skip when discovering files (e.g. `scratch.css`). Not applied when `domainsOrder` is set. |
| **`metaSourceStem`** | Which file supplies `@theme` meta (`--theme-default`, `--theme-cols`) and grid cols fallback. Default: stem `tokens`, else first domain. |
| **`banner`** | First line(s) of the generated `.ts` (default: `// Auto-generated from CSS…`). |
| **`verbose`** | Print resolved config path, `cssDir`, cascade order, and output path. |
| **`watch`** | Watch `cssDir` and regenerate on change. Same as CLI `--watch`. Use **`--no-watch`** to run once even if `watch` is `true` in config. |

### Shipped defaults (`packages/styles/defaults`)

If you point at this package’s `defaults` folder **without** `domainsOrder` and without CLI `--domains`, the order is fixed to `tokens` → `palette` → `theme` (alphabetical order would break token resolution).

### CLI overrides

| Flag | Effect |
|------|--------|
| `--from-css <dir>` | Input directory |
| `-o` / `--output <dir>` | Output **directory** for `styles.generated.ts` |
| `--domains a,b,c` | Stems in order |
| `--config <path>` | Use this JSON file instead of searching |
| `--no-config` | Ignore config files |
| `--verbose` / `-v` | Same as `react33Styles.verbose: true` |
| `--watch` / `-w` | Same as `react33Styles.watch: true` (overrides `false` in config) |
| `--no-watch` | Force a single run (`react33Styles.watch` ignored) |
